# 生产初始化与首个管理员

更新日期：2026-07-15

## 原则

- `npm run db:seed` 只写入系统配置、角色权限、贷款产品、定价规则和首个超级管理员。
- 种子脚本不包含默认密码，不创建经理、财务、操作员、客户或资金方测试账号。
- 已存在可用超级管理员时，重复执行种子不会读取密码变量，也不会重置任何账号密码。
- 旧版本种子创建的公开默认账号会被识别：超级管理员原记录强制轮换，其他默认账号停用。
- 仓库不提供会绕过业务服务写资金记录的演示造数或清库命令。

## 首次执行

首次执行且数据库尚无可用超级管理员时，临时设置：

```powershell
$env:BOOTSTRAP_ADMIN_USERNAME = "internal.admin"
$env:BOOTSTRAP_ADMIN_PASSWORD = "使用密码管理器生成的强随机密码"
$env:BOOTSTRAP_ADMIN_REAL_NAME = "内部管理员"
npm run db:seed
Remove-Item Env:BOOTSTRAP_ADMIN_PASSWORD
```

密码必须为 16-128 个字符，同时包含大小写字母、数字和符号，并且不能包含管理员用户名。用户名必须以字母开头，只允许字母、数字、点、下划线和连字符。

## 重复执行

数据库已经存在启用且未删除的超级管理员时，直接执行：

```powershell
npm run db:seed
```

脚本只补齐系统配置，不修改现有管理员密码。若引导用户名已被停用账号或非超级管理员占用，脚本会失败并要求人工核查，不会覆盖账号。

如果检测到旧版本公开默认密码，仍需临时提供 `BOOTSTRAP_ADMIN_PASSWORD`。脚本在同一事务中保留原超级管理员 ID、更新用户名和密码，并停用遗留经理、财务和操作员账号。

## 后续账号

首个管理员登录后，在后台用户管理中分别创建经理、财务和操作员，并按实际职责分配角色。禁止共享首个管理员密码。
